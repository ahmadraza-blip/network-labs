# Packet Tracer Labs

Hands-on labs built in Cisco Packet Tracer, progressing from basic
connectivity to routing.

| # | Lab | Topics |
|---|-----|--------|
| 01 | Router to Router | Router links, ping tests |
| 02 | Multi-Router Wireless | Multi-router design, wireless, servers |
| 03 | Client-Server | Static IP |
| 04 | Switch Static IP | Switching, static addressing |
| 05 | Switch DHCP | DHCP server, dynamic addressing |
| 06 | Hub Static IP | Hubs, static addressing |
| 07 | Hub DHCP | Hubs, DHCP |
| 08 | Switch 6 Devices | Switching, static addressing |
| 09 | Two Switches DHCP | Multi-switch LAN, DHCP |
| 10 | Router Two LANs | Inter-network routing |
| 11 | DHCP Relay | ip helper-address |
| 12 | Router Three Subnets | Subnetting, routing |
| 13 | Static Routing | ip route, multi-router |
| 14 | RIPv2 + DHCP Relay | Dynamic routing, DHCP relay |
