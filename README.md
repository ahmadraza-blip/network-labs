# Network Labs

Hands-on networking labs built in Cisco Packet Tracer as a foundation
for a SOC Analyst career.

## What's inside

| Folder | Description |
|--------|-------------|
| [packet-tracer-labs](packet-tracer-labs) | 14 labs: static IP, DHCP, hubs, switches, DHCP relay, static routing, RIPv2 |

## Skills practiced

- IP addressing (static and DHCP)
- Switching and hubs
- Routing (static and RIPv2)
- DHCP relay (`ip helper-address`)
- Network troubleshooting with ping

## Roadmap

- [ ] VLANs and trunking
- [ ] ACLs
- [ ] NAT
- [ ] Port security
- [ ] Syslog and logging

## Tools

Cisco Packet Tracer

## How to Open a Lab

1. Install Cisco Packet Tracer
2. Open the **packet-tracer-labs** folder and click the `.pkt` file
3. Click the download icon (top right)
4. Double-click the downloaded file, or use File > Open in Packet Tracer
